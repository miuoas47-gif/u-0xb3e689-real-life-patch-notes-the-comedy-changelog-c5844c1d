A one-line comedy patch note for a bug in real life: walking through a doorway wipes your short-term memory. `main.py` writes that single line (96 characters) to `entry.txt`, validating it is one line of 1–160 characters and verifying the written bytes by reading them back.

## Run it

```sh
python3 main.py
```
